# Karthika Damodara Vratham

A free devotional challenge for children ages 6–15 in and around Vizag, October 26–November 25, 2026.

## Vercel

Import this repository into Vercel. Framework: **Next.js**. Root directory: **./**. Build: `npm run build`. Node.js: **22.x or newer**. No environment variables are needed to preview the informational website.

The registration, private photo/video upload and organizer attendance features need a Supabase project. Run `supabase/schema.sql` in its SQL editor and add the variables from `.env.example` in Vercel. Detailed setup instructions are being added as the forms are completed.

## Local development

```sh
npm install
npm run dev
```

The dates include **31 calendar days**. All deadlines use Asia/Kolkata (IST).
